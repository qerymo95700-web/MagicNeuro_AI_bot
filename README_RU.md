# Telegram AI-бот — стартовый проект

Бот предназначен для запуска в облаке и управления через Telegram на iPhone.
На самом iPhone сервер держать необязательно.

## Что умеет
- подтверждение 18+ (самодекларация, не является проверкой личности);
- генерация изображений;
- редактирование присланного фото по подписи;
- базовые проверки запросов и модерация API-провайдера.

## Важные ограничения
Бот не предназначен для создания сексуализированных изображений несовершеннолетних,
включая вымышленных персонажей, интимных дипфейков или интимных изображений реальных
людей без согласия. Подтверждение возраста кнопкой не доказывает возраст пользователя.
Не рекламируй этот бот как сервис без ограничений.

## 1. Создай Telegram-бота
1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, выбери имя и username.
3. Скопируй токен. Никому его не отправляй и не публикуй.

## 2. Получи API-ключ изображений
Создай API key в OpenAI Platform и проверь, что у проекта есть доступ и биллинг
для GPT Image. Официальная документация:
https://developers.openai.com/api/docs/guides/image-generation

## 3. Запуск локально или на хостинге
Нужен Python 3.11+.
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
Заполни `.env`, затем:
```bash
export $(grep -v '^#' .env | xargs)
python bot.py
```

Для постоянной работы разверни проект на облачном хостинге, который поддерживает
Python worker/background process. В настройках хостинга добавь переменные
`TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY` и `IMAGE_MODEL`. Не загружай `.env` в GitHub.

## Примечания
- Это стартовый шаблон, не готовый коммерческий сервис.
- Возрастная кнопка — только подтверждение пользователя; для коммерческого 18+ сервиса
  нужна отдельная юридическая и техническая оценка возрастной проверки и местных законов.
- Базовые фильтры в коде не заменяют полноценную модерацию. Перед публичным запуском
  добавь лимиты запросов, журналирование без хранения лишних персональных данных,
  обработку жалоб и защиту от злоупотреблений.
